# Onyx Build & Partners

Premium website for **Onyx Build & Partners Limited** — Lighting, Sanitary Ware & Home Solutions.

> Redefining Modern Living

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Pages

- **Home** — Hero, categories, collections, showroom flow
- **Lighting** — Pendant, ceiling, outdoor, smart & decorative lighting
- **Sanitary Ware** — Luxury bathrooms, faucets, showers & accessories
- **Home Solutions** — Kitchen, smart home, storage & renovation services
- **Inspiration** — Project gallery and design concepts
- **Consultation** — Book interior, product, or showroom consultations

## Tech Stack

- [Next.js 16](https://nextjs.org/) (App Router)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS 4](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
